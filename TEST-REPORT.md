# Отчет о проверке версии 3.0

Дата проверки: 13.09.2026.

## Интерфейс и браузеры

- Полный автоматический прогон версии 3.0 выполнен в Chromium; тот же постоянный набор настроен для Chromium в GitHub Actions.
- Проверены размеры 1920×1080, 1366×768, 1024×768, 402×874, 390×844 и 320×568, отсутствие горизонтальной прокрутки, полноэкранный просмотр и масштабирование.
- Отдельно проверены показ ошибок пустой формы, автосохранение, подтверждение очистки, выгрузка и остановка выгрузки при переполнении шаблона.
- Настольный Safari проверен вручную: локальная версия 3.0 загружается, обновленная шапка отображается корректно, собственный список Исполнителя имеет белый фон и показывает только полные наименования четырех вариантов.
- Нижняя кнопка установки, инструкции в моделируемых режимах Safari на macOS и iPhone, адаптивная компоновка и автономная загрузка повторно проверены после переноса кнопки.
- Семантические `legend` сохранены для экранных дикторов, а видимые заголовки перенесены внутрь карточек: выступание над рамкой в Safari устранено.
- Проверены именованные черновики, переключение с сохранением данных, повтор предыдущего акта с очисткой номера и дат, поиск, выбор, изменение и удаление карточек заказчиков, подписантов обеих сторон и типовых услуг, значения по умолчанию и режим без сохранения.
- Проверены клавиатурное управление собственными списками, их явная светлая цветовая схема при темной теме и отсутствие горизонтальной прокрутки после добавления управляющих кнопок.
- Проверены экспорт переносимой JSON-копии и восстановление двух черновиков, карточек обеих сторон, типовых услуг и настроек после подтверждения замены.
- Проверено сохранение просроченных по обычному правилу данных после установки приложения и отображение срока «без ограничения».
- Проверены блокировка даты акта раньше договора, отклонение имен с цифрами и бессодержательных оснований полномочий.
- На ширине 402 px оба поля даты остаются внутри карточек. Мобильная версия использует сплошные светлые фоны без `backdrop-filter` и маски изображения, которые вызывали артефакты полного снимка Safari.
- На 1920×1080 и 1366×768 проверены полезная ширина до 1720 px, шапка не выше 90 px, поля не выше 38 px, близкая типографическая шкала подписей и значений и высота формы не более 920 px на Full HD.
- Карточка ссылки проверена в размере 1200×630; в ней нет миниатюры страницы, текст и назначение сервиса читаются крупно.
- Проверены восемь экземпляров предметных цветных пиктограмм документов, подписи, предпросмотра, защиты, повтора и Excel. Остальные служебные SVG используют единый внешний комплект `assets/icons-v2.9.svg`; встроенных разрозненных контуров в HTML нет.

## Расчеты и варианты Исполнителя

- Проверены все четыре варианта Исполнителя.
- Для каждого варианта проверен соответствующий пример номера договора в поле ввода.
- Ставки НДС 22% и 5%, суммы НДС, подписанты и тексты Исполнителя совпадают с версией 2.3.
- Для варианта по доверенности проверены три условно обязательных поля и их попадание в акт.
- Проверены единицы, тысячи, миллионы, копейки и округление суммы прописью.

## XLSX

- Встроенный файл шаблона совпадает с версией 2.3 побайтно, SHA-256: `638a4ef82e17d4e5611cf6e8a0ea926eeabf09bb5fdbdea0484927e2cd3c5e42`.
- Каждый из четырех вариантов сформировал корректный ZIP/OOXML без внешних связей и формул.
- В каждой книге один лист `Акт`, диапазон `A1:J55`, формат печати A4 portrait и одна страница.
- Вариант по доверенности дополнительно открыт LibreOfficeDev 26.8 и отрисован в одностраничный PDF A4 без обрезки.
- Для версии 3.0 повторно сформированы все четыре варианта; каждый файл прошел браузерную проверку формирования и загрузки, встроенный шаблон не изменялся.
- Проверен обратный импорт обычного варианта и варианта по доверенности с восстановлением реквизитов и повторной выгрузкой.
- Встроенный шаблон версии 3.0 не изменен, SHA-256: `638a4ef82e17d4e5611cf6e8a0ea926eeabf09bb5fdbdea0484927e2cd3c5e42`.

## PWA и доступность

- Новый кэш `acts-constructor-v3.0.0-20260913-r2` содержит HTML, стили, оба сценария приложения, XLSX-шаблон, шрифты, изображения и комплект иконок.
- Проверена загрузка версии 3.0 и встроенного XLSX-шаблона без сети.
- Видимые подсказки суммы, длинных значений и счетчика услуги связаны с полями через `aria-describedby`; динамические ошибки добавляются в ту же связь.

## Ограничения проверки

Не выполнялись отдельные живые прогоны в Microsoft Edge, Firefox, Excel для Windows, iPhone и iPad. Совместимость этих сред обеспечивается стандартным HTML/CSS, форматом OOXML и PWA-механизмами, но не заявляется как проверенная на реальных устройствах в этом прогоне.
