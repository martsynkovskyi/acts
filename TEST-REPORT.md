# Отчет о проверке версии 2.5

Дата проверки: 12.09.2026.

## Интерфейс и браузеры

- Полный автоматический прогон выполнен в Яндекс Браузере и Chromium-Gost; тот же постоянный набор настроен для Chromium в GitHub Actions.
- Проверены ширины 1440, 1024, 390 и 320 px, отсутствие горизонтальной прокрутки, полноэкранный просмотр и масштабирование.
- Отдельно проверены показ ошибок пустой формы, автосохранение, подтверждение очистки, выгрузка и остановка выгрузки при переполнении шаблона.
- Настольный Safari проверен вручную: загрузка версии 2.5, регистрация автономного режима, семантическая структура полей и компоновка разделов работают.
- Нижняя кнопка установки, инструкции в моделируемых режимах Safari на macOS и iPhone, адаптивная компоновка и автономная загрузка повторно проверены после переноса кнопки.
- Семантические `legend` сохранены для экранных дикторов, а видимые заголовки перенесены внутрь карточек: выступание над рамкой в Safari устранено.
- Проверены именованные черновики, переключение с сохранением данных, повтор предыдущего акта с очисткой номера и дат, карточки заказчиков и подписантов, типовые и недавние услуги, значения по умолчанию и режим без сохранения.
- Проверены блокировка даты акта раньше договора, отклонение имен с цифрами и бессодержательных оснований полномочий.

## Расчеты и варианты Исполнителя

- Проверены все четыре варианта Исполнителя.
- Ставки НДС 22% и 5%, суммы НДС, подписанты и тексты Исполнителя совпадают с версией 2.3.
- Для варианта по доверенности проверены три условно обязательных поля и их попадание в акт.
- Проверены единицы, тысячи, миллионы, копейки и округление суммы прописью.

## XLSX

- Встроенный файл шаблона совпадает с версией 2.3 побайтно, SHA-256: `638a4ef82e17d4e5611cf6e8a0ea926eeabf09bb5fdbdea0484927e2cd3c5e42`.
- Каждый из четырех вариантов сформировал корректный ZIP/OOXML без внешних связей и формул.
- В каждой книге один лист `Акт`, диапазон `A1:J55`, формат печати A4 portrait и одна страница.
- Вариант по доверенности дополнительно открыт LibreOfficeDev 26.8 и отрисован в одностраничный PDF A4 без обрезки.
- Для версии 2.5 повторно сформированы все четыре варианта; каждый файл прошел проверку целостности ZIP/OOXML.
- Проверен обратный импорт обычного варианта и варианта по доверенности с восстановлением реквизитов и повторной выгрузкой.
- Встроенный шаблон версии 2.5 не изменен, SHA-256: `638a4ef82e17d4e5611cf6e8a0ea926eeabf09bb5fdbdea0484927e2cd3c5e42`.

## PWA и доступность

- Новый кэш `acts-constructor-v2.5-20260912` содержит HTML, стили, оба сценария приложения, XLSX-шаблон, шрифты, изображения и иконки.
- Проверена загрузка версии 2.5 и встроенного XLSX-шаблона без сети.
- Видимые подсказки суммы, длинных значений и счетчика услуги связаны с полями через `aria-describedby`; динамические ошибки добавляются в ту же связь.

## Ограничения проверки

Не выполнялись отдельные живые прогоны в Microsoft Edge, Firefox, Excel для Windows, iPhone и iPad. Совместимость этих сред обеспечивается стандартным HTML/CSS, форматом OOXML и PWA-механизмами, но не заявляется как проверенная на реальных устройствах в этом прогоне.
