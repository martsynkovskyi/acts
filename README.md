# Конструктор актов

Сервис для подготовки актов сдачи-приемки оказанных услуг по договорам Центрального офиса Русского Регистра. Заполненный акт можно проверить в предпросмотре и скачать в редактируемом формате XLSX.

## Возможности

- Выбор исполнителя, автоматический расчет НДС и запись стоимости прописью в акте.
- Справочники заказчиков, подписантов исполнителя по доверенности и формулировок услуг. Для одной компании можно сохранить несколько карточек с разными представителями; записи можно изменять и удалять.
- Шаблоны заполнения актов, повтор предыдущего акта и настройка значений по умолчанию.
- Оформление на выбор: «Как в системе», «Светлая» или «Темная».
- Проверка заполнения перед скачиванием и предварительный просмотр готового акта.
- Загрузка данных из XLSX, ранее созданного сервисом, и резервное копирование сохраненных данных.

## Хранение данных

Данные остаются на устройстве в используемом браузере и не передаются на сервер. Сохранение можно отключить или выбрать срок: 30 дней, полгода, год либо без ограничения срока. По умолчанию выбран режим без ограничения срока.

Сервис можно установить как приложение и после первого открытия использовать без интернета.

## История версий

### 3.1 - 18.09.2026

- «Черновики» переименованы в «Шаблоны». В настройках можно скачать пустой шаблон акта; значения по умолчанию сразу заполняют пустые поля.
- В реквизитах используются кавычки «елочки». Для одной компании можно сохранить карточки с разными представителями.
- Дата договора в акте выводится в формате ДД.ММ.ГГГГ. Предпросмотр точнее соответствует итоговому XLSX и подстраивается под высоту формы.
- Обновлено оформление для компьютеров и телефонов. Добавлены светлая и темная темы оформления с режимом «Как в системе».
- Очистку формы можно отменить в течение 10 секунд. После обновления показывается окно «Что нового?»; описание сервиса и история версий доступны по нажатию на номер версии.

### 3.0 - 13.09.2026

- Форма перестроена в три блока: «Исполнитель», «Заказчик», «Договор». Поля размещены компактнее для экранов Full HD.
- Карточка заказчика теперь включает сведения о компании и ее представителе. Для исполнителя по доверенности предусмотрен отдельный справочник подписантов.
- Добавлен выбор срока хранения данных. Обновлены оформление сервиса, значок приложения и изображение при отправке ссылки.

### 2.9 - 13.09.2026
