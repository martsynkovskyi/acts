# Конструктор актов

Сервис для подготовки актов сдачи-приемки оказанных услуг по договорам Центрального офиса Русского Регистра. Заполните реквизиты, проверьте предпросмотр и скачайте редактируемый акт в формате XLSX.

## Возможности

- Выбор одного из четырех Исполнителей с автоматическим расчетом НДС и суммы прописью.
- Карточки Заказчиков со сведениями об их представителях, справочник подписантов Исполнителя по доверенности и типовые формулировки услуг. Сохраненные записи можно изменять и удалять.
- Несколько сохраняемых шаблонов, повтор предыдущего акта и настройка значений по умолчанию.
- Автоматическая замена прямых двойных кавычек на «елочки» в реквизитах и справочниках.
- Скачивание пустого бланка акта XLSX без заполнения формы.
- Проверка заполнения и размещения текста до скачивания акта. Предпросмотр показывает структуру итогового файла.
- Загрузка данных из XLSX, ранее созданного этим сервисом, и переносимая резервная копия рабочих данных.

## Данные и установка

Данные хранятся только в используемом браузере и не передаются на сервер. Сохранение можно отключить или выбрать срок: 30 дней, полгода, год либо без ограничения. По умолчанию выбран бессрочный режим.

Сервис можно установить как приложение. После первого открытия он работает без интернета; в установленном приложении срок хранения данных не ограничен.
