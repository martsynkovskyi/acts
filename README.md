# Конструктор актов v3.0

Статический сервис для подготовки актов сдачи-приемки оказанных услуг по договорам Центрального офиса Русского Регистра.

## Возможности

- четыре варианта Исполнителя: Ассоциация Русский Регистр, Ассоциация по доверенности, ООО «РР МС», ООО «РРС»;
- пример номера договора автоматически меняется по Исполнителю: `26.001.01.026РР`, `26.001.01.026РР-МС` или `26.001.01.026РРС`;
- автоматический расчет НДС 22% или 5%;
- сумма цифрами и прописью с корректными копейками;
- даты в формате `1 января 2026 г.`;
- живой предпросмотр по геометрии Excel-шаблона;
- полноэкранный просмотр, масштабирование до 240% и жест изменения масштаба;
- отдельный адаптивный блок предпросмотра с полноэкранным режимом на телефоне;
- обязательная проверка полей и размещения длинных значений до выгрузки;
- выгрузка редактируемого `.xlsx` с листом `Акт`;
- обычный режим открытия книги Excel;
- автоматическая очистка внутренних метаданных и офисных путей исходного шаблона;
- локальное автосохранение черновика, явные состояния выгрузки и подтверждение очистки с отменой;
- несколько именованных черновиков и повтор предыдущего акта с очисткой номера и дат;
- единые карточки Заказчиков со связанными сведениями о представителе и отдельный справочник подписантов Исполнителя по доверенности;
- собственные светлые списки сохраненных карточек и типовых услуг, читаемые при темной системной схеме;
- создание, изменение и удаление ранее сохраненных карточек Заказчиков, подписантов Исполнителя и наименований услуг;
- настраиваемые значения по умолчанию для города, места оказания услуг и даты акта;
- импорт `.xlsx`, ранее созданного этим сервисом;
- управляемый срок хранения 30 дней, полгода, 1 год или без ограничения срока и режим без сохранения данных;
- режим «Навсегда» по умолчанию в браузере и автоматическое переключение на него при установке приложения;
- переносимая резервная копия черновиков, карточек, типовых услуг и значений по умолчанию;
- смысловая проверка последовательности дат, имен подписантов и оснований полномочий;
- адаптивный интерфейс для desktop, tablet и mobile;
- плотная строковая компоновка для экранов Full HD без уменьшения читаемости подписей;
- безопасная ширина системных полей даты на мобильных устройствах и стабильный полноэкранный снимок Safari;
- собственный доступный список Исполнителя в едином стиле со справочниками;
- отдельная крупная карточка ссылки 1200×630 без миниатюры интерфейса;
- предметные цветные пиктограммы документов, подписи, предпросмотра, защиты и Excel; служебные элементы управления используют единый вспомогательный комплект;
- интерфейс на локальном шрифте Golos Text, без CDN и внешних запросов.

## Публикация на GitHub Pages

1. Загрузить содержимое архива в корень репозитория.
2. В настройках Pages выбрать публикацию из нужной ветки и корневой папки.
3. Файл `CNAME` уже содержит домен `acts.martsynkovskyi.ru`.
4. После обновления Open Graph изображения мессенджеры могут некоторое время показывать старую закэшированную карточку.

## Безопасность и приватность

Сервис работает полностью в браузере. Данные не отправляются на сервер, не используются аналитика, трекеры, CDN и внешние API. В обычном браузере срок локального хранения задается пользователем. В установленном приложении срок не ограничен. Резервная копия создается как локальный JSON-файл и восстанавливается только после явного подтверждения замены текущих данных.

## XLSX-шаблон

Шаблон книги встроен в `assets/xlsx-template-v2.3.js`. При выгрузке сервис:

- подставляет данные пользователя;
- сохраняет исходное форматирование акта;
- переименовывает лист в `Акт`;
- включает обычный режим просмотра;
- удаляет принтерные настройки, сведения о совместном редактировании, старого автора и внутренние сетевые пути;
- задает актуальные свойства документа.

## Лицензия шрифта

Golos Text распространяется по SIL Open Font License 1.1. Текст лицензии включен в `LICENSE-OFL.txt`.


## Установка как приложение

Внизу сайта размещена кнопка «Установить приложение», как в сервисе «Сумма прописью». На Chrome и Edge она открывает системную установку. В Safari на macOS кнопка показывает шаги «Файл - Добавить в Dock…», на iPhone и iPad - «Поделиться - На экран Домой». После первого посещения сервис и XLSX-шаблон доступны без интернета.


## Автоматическая проверка

Постоянный браузерный набор находится в `tests/browser-regression.cjs`. Он проверяет четыре варианта Исполнителя, динамические примеры номеров договоров, смысловую валидацию, экспорт и обратный импорт XLSX, повтор акта, поиск, применение, изменение и удаление сохраненных записей, светлый список при темной системной схеме, именованные черновики, резервное копирование и восстановление, бессрочное хранение установленного приложения, режим без сохранения, адаптивность и автономную загрузку. GitHub Actions запускает этот набор при каждом pull request и push в `main`.

## Версия

**3.0 от 13.09.2026**

Версия 3.0 получила новую структуру из трех логичных блоков: «Исполнитель», «Заказчик» и «Договор». Карточка Заказчика хранит все связанные сведения о его представителе, а для Исполнителя по доверенности предусмотрен отдельный справочник с выбором по имени. Форма уплотнена для Full HD, последние поля собраны в одну строку, лишняя расшифровка стоимости удалена из интерфейса, а расчеты НДС и суммы прописью сохранены в акте и XLSX. Срок хранения данных теперь выбирается пользователем и реально применяется. Обновлены шапка, карточка ссылки, значок приложения и единая система предметных пиктограмм.
