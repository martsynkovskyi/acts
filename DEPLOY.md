# Публикация Конструктора актов 3.1

Сайт публикуется из корня ветки `main` репозитория `martsynkovskyi/acts` через GitHub Pages. Файл `CNAME` задает домен `acts.martsynkovskyi.ru`.

Перед публикацией запустите `npm test` и дождитесь успешной проверки Regression QA в GitHub Actions. Не изменяйте встроенный XLSX-шаблон `assets/xlsx-template-v2.3.js` при очистке старых файлов: он используется текущей версией.

После публикации дождитесь успешной сборки GitHub Pages и проверьте на работающем сайте страницу, `manifest.webmanifest`, `service-worker.js`, значки и формирование XLSX. Для установленного приложения обновление Service Worker может потребовать подтверждения пользователя. Кеш подготовленного обновления: `acts-constructor-v3.1.0-20260917-r1`.

Рабочая версия содержит только подключенные файлы и исходные материалы оформления. Прежние версии доступны в истории Git; их не нужно возвращать в корень сайта. При изменении изображения карточки ссылки используйте новое имя файла, чтобы мессенджеры не показывали старое закешированное превью.
