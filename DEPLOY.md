# Публикация «Конструктора актов» 2.4

Загрузите все файлы из архива в корень репозитория GitHub Pages. Файл `CNAME` уже содержит `acts.martsynkovskyi.ru`.

PWA-файлы `manifest.webmanifest` и `service-worker.js` должны оставаться в корне, чтобы приложение устанавливалось и работало без интернета.

Публикуйте содержимое архива целиком за один раз. Версия 2.4 использует новые имена CSS и JavaScript и отдельный кэш `acts-constructor-v2.4-20260912`, поэтому смешивать файлы версий 2.3 и 2.4 не следует.

После публикации откройте сайт с интернетом хотя бы один раз. Если приложение уже было установлено, оно покажет состояние «Доступно обновление» и применит новую версию только после подтверждения пользователя.
